# Crear un proyecto

Segundo tutorial del centro de ayuda de AETHER. Duración: 45,625 segundos. Usa la misma identidad visual que «Orientarse entre espacios».

La interfaz es una recreación didáctica del flujo actual, con datos ficticios. Muestra el acceso «+» de Proyectos, los cuatro pasos del formulario, un proyecto Flexible y la trazabilidad avanzada como complemento opcional.

## Edición y render

- Composición: `index.html`
- Diseño y guion: `design.md`, `STORYBOARD.md`
- Subtítulos: `tutorial.es.vtt`
- Comprobación: `npx --yes hyperframes@0.8.179 check`
- Render local: `.\render.ps1`

El MP4 renderizado se copia a `apps/web/public/tutoriales/crear-un-proyecto.mp4` para el centro de ayuda.
