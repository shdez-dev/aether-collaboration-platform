## Alcance

Revisión estática de rutas HTTP, autenticación, editor colaborativo, cargas de archivos, configuración de despliegue y dependencias; compilación local y comprobaciones específicas. No se hizo una prueba de penetración ni se inspeccionó una sesión autenticada o un despliegue activo. El resultado no garantiza ausencia de otras fallas.

## Corregido en el árbol de trabajo

| Prioridad | Hallazgo | Cambio |
| --- | --- | --- |
| Alta, disponibilidad | El lockfile instalaba `prosemirror-view` 1.42.3 y 1.42.6. La excepción `localsInner` de la captura ocurre al montar el editor y es compatible con esa duplicación. | Unificación en 1.42.6 mediante `pnpm.overrides`; el lockfile ahora solo resuelve esa versión. |
| Alta, contenido activo | El avatar confiaba en el MIME declarado y conservaba la extensión enviada por el usuario. Un archivo con nombre `.html` podía quedar bajo `/uploads` en el mismo origen de la aplicación. | Validación de cabecera de imagen y extensión pública derivada del tipo comprobado. |
| Media, permisos y almacenamiento | Una persona con acceso `VIEW` podía llamar a `POST /api/documents/:id/versions` y crear copias persistentes del documento. | Se exige permiso efectivo `EDIT` y se limita la descripción a 300 caracteres. |
| Media, disponibilidad | Un evento `document:awareness:update` malformado o un error de consulta podía producir una promesa rechazada sin manejar. | Se validan los bytes y el tamaño, se captura el error; el guardado al desconectar se vuelve a programar si falla la limpieza. |

## Pendiente

| Prioridad | Hallazgo | Recomendación |
| --- | --- | --- |
| Alta si el servicio es público | Las rutas de inicio, registro y recuperación de contraseña no tienen límite de intentos. Se retiró deliberadamente el límite global por IP para evitar falsos positivos entre personas que comparten una IP, pero permite automatizar intentos si la API es alcanzable por terceros. | Aplicar controles por cuenta y por IP antes de exponer el servicio públicamente; mientras tanto, limitar el acceso mediante la capa de red o el proxy. |
| Media | El cambio de contraseña en `/api/users/me/password` acepta 6 caracteres, mientras registro y restablecimiento exigen al menos 8, una letra y un dígito. Además no revoca los refresh tokens existentes. | Unificar la política y cerrar las sesiones existentes tras el cambio con una transición clara en la interfaz. |
| Media | El frontend persiste access y refresh tokens en `localStorage`. Si aparece un XSS en cualquier pantalla del mismo origen, el script puede leerlos. | Evaluar cookies `HttpOnly` y una política CSP en el frontend como cambio de arquitectura de autenticación. |
| Media, rendimiento | `GET /api/documents/:id/versions` selecciona el estado Yjs binario de **todas** las versiones y lo devuelve al cliente para una lista. Documentos con muchas versiones pueden producir respuestas grandes. | Separar listado de metadatos y descarga de una versión concreta; paginar el listado. |
| Seguimiento | `pnpm audit` marca `braces@3.0.3` como alta porque no existe una versión publicada corregida para el aviso GHSA-vfj7-8cjw-p6xm. El repositorio contiene un parche de límite de profundidad, y `node scripts/check-braces-patch.cjs` lo confirmó en esta instalación. | Mantener el parche y su comprobación en CI hasta disponer de una versión upstream corregida. |
