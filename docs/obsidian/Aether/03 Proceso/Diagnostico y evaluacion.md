# Diagnostico y evaluacion

## Separación de propósitos

El diagnóstico mejora la comprensión del problema. La evaluación determina si una propuesta satisface criterios de decisión. La aprobación autoriza continuar bajo condiciones. Deben distinguirse porque requieren información y autoridad diferentes.

## Diagnóstico objetivo

El mentor trabaja con el solicitante para delimitar beneficiarios, situación actual, causas observables, restricciones, intentos previos e hipótesis de solución. Se debe distinguir evidencia de opinión y registrar incertidumbres relevantes.

El resultado mínimo es un problema comprensible, una hipótesis contrastable, un alcance inicial, riesgos, recursos estimados y el próximo experimento o entregable. Si la información sigue siendo insuficiente, se devuelve a elaboración con observaciones concretas y fecha.

## Rúbrica propuesta

| Dimensión | Pregunta | Evidencia esperada |
| :--- | :--- | :--- |
| Pertinencia | ¿Responde al propósito del programa? | Relación con objetivos declarados |
| Necesidad | ¿Existe un problema relevante? | Datos, entrevistas o antecedentes |
| Viabilidad | ¿Es realizable en el contexto? | Recursos, capacidad y restricciones |
| Valor | ¿Qué mejorará para el beneficiario? | Resultado y medida esperada |
| Preparación | ¿Existe base para comprometer trabajo? | Responsable y próximos pasos |
| Riesgo | ¿Qué puede impedir o perjudicar el resultado? | Riesgos y tratamientos |
| Sostenibilidad | ¿Quién continuará después de entregar? | Responsable de operación o seguimiento |

Las dimensiones, escalas y pesos son configurables y versionados. Ninguna puntuación agregada sustituye automáticamente una condición excluyente. Un requisito obligatorio incumplido impide aprobar aunque el promedio sea alto.

## Independencia y trazabilidad

Cada evaluación se vincula a una versión del expediente y de la rúbrica. El evaluador declara conflicto de interés y puede abstenerse. La reasignación conserva el historial. Las notas privadas del comité y la devolución al solicitante son campos separados con audiencias explícitas.

La evaluación puede estar en borrador, presentada o rectificada. Rectificar crea una versión posterior y conserva la previa. No se debe sobrescribir una evaluación utilizada para aprobar.

## Decisión

La salida debe ser aprobada, devuelta para cambios, declinada o pausada. Aprobar indica condiciones, autoridad y vigencia si aplica. La devolución identifica faltantes accionables. Declinar conserva el fundamento y evita una notificación ambigua de «error».

El esquema de red ya contiene criterios y puntuaciones de evaluación. La inspección no certifica un circuito completo de abstención, revisión independiente y versionado de rúbricas; se incorpora como requisito del producto objetivo.

## Criterio de aceptación

Dos evaluadores autorizados pueden emitir resultados sin modificar la evaluación del otro. Un solicitante no puede leer deliberaciones reservadas. Una modificación material de la propuesta después de evaluar solicita nueva revisión o aceptación explícita del cambio.
